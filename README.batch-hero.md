# 批量主图

DeepSeek Harness 侧栏插件。打开活动 PSD，标出商品位，把一批 SKU 抠图灌进去，在画布上直接改，最后一键导出全部主图。

打开方式有三个，随便哪个：

- **会话上方的标签**：「对话 | 轨迹 | 批量主图」，和聊天并排，切过去聊天输入框还在
- 侧栏的「批量主图」图标
- 顶栏 `⋯` 里没有入口

工作台是常驻的：切回对话后它仍在后台跑，自然语言指令照样能送进去执行。面板顶栏有 `← 对话` 一键回去。

## 界面

**左栏 · 图层**

- 完整图层树，分组可折叠，搜索框过滤。
- 眼睛图标控制这一层进不进图，改完立刻重新合成。
- ◎ 把图层标成商品位，标中的层从底图里挖掉换成 SKU。
- 「自动识别」按内容打分挑商品位，不是只看名字：
  - 面积占比、宽高比（要竖着）、离画布中心的距离，先筛一遍
  - 名字里带「商品 / 产品 / 瓶 / 管 / 盒」加分，带「文字 / logo / 价格 / 背景 / 矩形」减分
  - 挑出最高分后，把**同尺寸、同排**的图层一起带出来，所以并排两个瓶子会一起认出来

**界面（v1.5 起为蓝白配色，结构参考 Balsa / Motion 的克制排版）**

- 顶栏：标题 + **文件 / 编辑 / 视图** 菜单 + 文档标签（右侧 `×` 清除模板）+ 导出格式与「导出全部」
- 左列：标题行（小号字距标签 + 计数 + 商品位徽标 + 识别按钮）→ 搜索 + 类型筛选（全部/文字/图片/分组）→ 图层树
- 中列：画布，尺寸按模板宽高比、默认比窗口大 5%
- 右列：`商品替换要素`（单列大卡片 + 常驻「＋ 添加商品图」大按钮）、属性区（各自一条滚动轴）
- 底栏：缩放比例、文档尺寸、状态提示
- 面板容器如果没有确定高度（放在自适应容器里），mount 时会按父级或视口强制定高，否则内部滚动条不会出现
- 用 `:where()` 写按钮基础重置，避免把 `.bh-btn` / `.bh-add` 自己的边框背景顶掉（v1.2 那个坑）
- 配色：白底 + `#F6F8FC` 冷灰、边框 `#E6EBF4`、主蓝 `#2563EB` 只用在主按钮 / 选中边框 / 滑块；选中行用「白底 + 细边框」而不是彩色底

**中间 · 画布**

- 点选图层的优先级：像素命中 → 文字按外框命中 → 已选图层的框内空白 → 包含该点的最小外框。左栏同步高亮并自动展开父组。
- 选中后出现变换框：四角缩放、四边单轴拉伸、顶上圆点旋转。
- `Shift` 等比，`Alt` 以中心缩放，旋转时 `Shift` 吸附 15°。
- 选中后**整个框内部都能拖**（透明处也算），方向键微移 1px（Shift 10px）。
- `Alt` + 点击可以穿透选中框和商品，直接选下面的图层。
- 图层重叠时 Shift+点在同一点的多个图层之间循环。
- **画布就是模板那张纸**：加载后按模板像素 1:1 铺开（1440×1920 就是 1440×1920），放不下由中间区域的滚动条接住；按 `0` 一键适应窗口看全貌。
- 空白处（画布内或纸外面的灰底）拖动 = 平移画布，滚轮缩放（以光标为锚点），`Shift` + 滚轮横向滚动，双击复位，Esc 取消选择。
- 左上角浮动条：`-` / `+` / 适应窗口 / `1:1` 实际像素 / 居中。
- 三条互不打扰的常驻滚动轴：左栏「图层」、右栏「商品替换要素」、右栏属性区（变换/颜色效果/画布微调）各一条，窗口再矮也能滚到底。
- **直接拖商品换位置**（按住 Alt 点商品则是选它下面的图层）。
- **拖商品位**：按住左上角那块「商品位」标签拖动，商品跟着走；有参考线吸附，`Cmd/Ctrl` 临时关掉。边框和内部都只用来选图层。
- 选中 SKU 后，四角缩放、圆点旋转、Alt+滚轮缩放商品。
- 商品按**抠图的实际内容**（透明像素包围盒）适配槽位，四周透明边不对称也不会偏。
- 「完整放入」默认占位比例 100%，即占满槽位；要留白再往下调。

### 对齐参考线

拖动图层或商品靠近时，会出现洋红色参考线并自动吸附：

- 图层：与其他可见图层的边缘、中心，以及画布边缘和中心对齐。
- 商品：与商品位的边缘、中心，以及画布边缘和中心对齐。
- 吸附阈值 6 屏幕像素；按住 `Cmd/Ctrl` 拖动可临时关掉吸附。

**右栏 · 商品替换要素 / 变换 / 文字 / 画布微调**

- 变换：宽、高、角度直接输入；等比开关；翻转 H / 翻转 V / 重置。
- 文字：选中文字层才会出现，可改内容、字体、字号、字重、颜色、字距、行高、对齐，并「恢复原文」。
  - **逐段保留原样式**：PSD 里一段文字常常混排多种字体和字号（比如价格「￥69.5/50g」是 5 段，￥ 小、69 大、/50g 小），编辑后各段不变。
  - 新打的字**继承前一个字**的字体字号。
  - 选中一段文字再改字体/颜色/字距，只作用于选中的那部分。
  - 「字号」是整体缩放，保留段与段之间的相对大小。
- 画布微调：适配方式、对齐、占位比例、水平垂直、缩放、角度，作用于当前 SKU。
- 「同步到全部」把当前参数复制给所有 SKU。

## 元素图层

除了换商品，还可以往模板里加别的图层——和 Photoshop 里「置入」一样：

1. 左栏底部的「导入元素图层」，点选或把图片拖进去。
2. 图片会变成模板树里的一个普通图层，出现在最上层。
3. 选中它就能用同一套变换：拖动、四角缩放、四边拉伸、旋转、翻转、隐藏、方向键微移。
4. 默认排在商品下面；「变换」面板里勾上「盖在商品上面」就移到商品前面（角标、水印这类）。
5. 树里那一行悬停出现 `×`，点掉就删除。

元素会一起存进工程文件（图以 base64 内嵌），换机器打开还在。

## 文字能不能改

能，但要先说清楚边界：PSD 里文字层在读取后是**点阵**，不是可编辑的文字对象。我们做的是——把原文内容、字体名、字重、颜色、字距、行高、对齐抽出来，用浏览器重新排版一遍。

所以：

- 改文案、换字体、调字号字重颜色，都会立刻重排并保持原来的位置和视觉大小。
- 排版引擎是浏览器的，跟 Photoshop 不是逐像素一致；细微的字距、标点挤压会有差异。
- 字体用系统里有的。选了没装的字体会回退到 PingFang SC。
- 字号显示的是「派生像素值」——按原来那块点阵的宽高反推出来的，不是 PS 里的 pt 数。

## 工程存档

右上角 `⋯` → 保存工程 / 载入工程。存成 `.json`，包含：

- 模板文件名、尺寸、**原始路径**
- 商品位（按图层路径记录，例如 `小白管50g*2 /名字/矩形 1 拷贝`）
- 每个图层改动：显隐、位移、缩放、旋转、文字改动
- 每张 SKU 的微调参数
- 默认位置参数和导出设置

载入时：

1. 工程里有模板路径 → 自动重新打开模板（走宿主文件通道）
2. 再按图层路径把改动套回去
3. SKU 还没导入也没关系，参数会挂着，之后导入同名的会自动套上

所以换电脑、换活动周期，打开工程就能回到上次的样子。

命令行也能用：

```js
batch_hero({ action: "save_project", path: "/Users/ethan/Projects/双11-主图工程.json" })
batch_hero({ action: "load_project", path: "/Users/ethan/Projects/双11-主图工程.json" })
```

## 用自然语言做

宿主注册了工具 `batch_hero`，可以在对话里直接说：

> 打开 2-长图.psd，把「形状 4 拷贝」当商品位，导入抠图文件夹，按高度贴底占位 92%，全部导到输出目录

| action | 作用 |
| --- | --- |
| action | 作用 |
| --- | --- |
| `status` | 当前模板、商品位、SKU、位置、选中图层的外观、视野 |
| `open` | 传 `path` 打开模板（PSD/PSB/PNG/JPG/WebP） |
| `close` | 卸掉模板，`keepSkus=false` 连商品要素一起清 |
| `import` | 传 `dir` 递归导入商品抠图 |
| `clearskus` / `remsku` | 清空全部 / 删掉一张（`name` 或 `index`） |
| `slot` | 商品位：`layers` + `mode=set`（默认）/`add`/`clear`，不传 `layers` 自动识别 |
| `place` | `fit` / `align` / `ratio` / `dx` / `dy` / `scale` / `rotation`，`scope=all` 套全部 |
| `select` | 传 `name` 或 `index` 选一张 SKU |
| `layer` | 传 `names`：变换、`slotDX/slotDY`、`followWidth`、`hidden`、`front`、`opacity`、`blend`、`tint`/`tintStrength`、`brightness`/`contrast`/`saturate`/`hue`/`blur`、`text`/`font`/`fontSize`/`fontSizePt`/`weight`/`tracking`/`leading`/`color`/`align`、`reset`、`resetLook` |
| `view` | `mode=fit/center/100/zoom`（配 `zoom`） |
| `showSlots` | 传 `show` 控制画布上的商品位框 |
| `format` | 导出格式 `png/jpg/webp/bmp/psd/psb`，可带 `quality`、`longEdge`、`square` |
| `element` / `remelement` | 往模板置入图片图层（`dir`/`paths`）/ 删元素图层（`names`） |
| `fonts` | 注册本地字体（`dir` 或 `paths`，ttf/otf/ttc/woff） |
| `undo` / `redo` | 撤销 / 重做（面板里任何一步都能回退） |
| `export` | 传 `dir` 和 `all`，宿主机直接写盘；格式取 `format` |
| `save_project` / `load_project` | 工程存 / 读 |

面板上的每一步都有对应动作，所以自然语言可以全程驱动：`open → slot → import → place → layer → format → export`。

前提：**面板要开着**。工具经 `/batch-hero/poll` 长轮询把指令送进面板，面板执行完回报；导出图走 `/batch-hero/write` 由宿主写盘。

文件读写都走宿主：`/batch-hero/file` 只放行 psd/psb/png/jpg/webp，且只接受本机请求。

## 导入

- 「载入模板」选 PSD / PSB。
- 画布中央的投放卡：点击选模板，或把 PSD 直接拖进来。
- **导出格式**：PNG / JPG（质量可调）/ WebP / BMP（24 位手工编码）/ PSD / PSB（ag-psd 写入，单图层、带缩略图、尺寸与画布一致）。
- 右栏「商品替换要素」：**列表下方常驻「＋ 添加商品图」大按钮**，加多少张都能继续加；也可以点「整文件夹导入」或直接把图片拖进去。支持 PNG / JPG / WebP / GIF / AVIF / BMP。
- 左栏底部「导入元素图层」：把图片作为模板元素放进去。
- 顶栏 `⋯` 里也保留了「载入模板（换掉当前的）」「清除模板」「导入 SKU（文件/文件夹）」作为备用入口；模板名字右边的 `×` 就是清除模板，换新模板时商品要素会保留。
- 文字层：改内容、字体、**字号（按画面上的像素显示/输入）**、字重、颜色、字距、行高、对齐。
  - 字号框显示的是「画面上量出来的像素大小」，输入多少就是多少；改字号只改字符自身的 pt，不再动内部整体缩放（`textEdit.scale` 恒定 1），所以**加字、换行、改字号都不会让整段文字突然缩小**。
- 字体：**「文件」菜单 →「导入字体…」**（和载入模板、载入工程放在一起）加载本地 ttf / otf / ttc / woff，TTC 取集合里第一个字重；导入后直接出现在文字面板的字体下拉里。通过宿主通道加载的字体地址会记在 localStorage，下次打开自动装回。
- 选中图层后右栏「变换」里可以直接调**不透明度**、**混合模式**、**隐藏这一层**；「恢复外观」把它们还原成 PSD 原值。
- 「颜色与效果」一组（对标 PS 的混合选项 + 调整图层、Figma 的图片调整）：
  - **颜色叠加**：取色器 + 「吸管」从屏幕上任意位置取色 + 强度滑杆，把图层染成品牌色
  - **亮度 / 对比度 / 饱和度 / 色相 / 模糊**，滑杆双击复位；全部即时预览、写进导出、进撤销栈和工程文件
- 拖拽时自动分辨：PSD 当模板，图片当 SKU。

## 不装 DeepSeek Harness 也能用

面板本身不依赖 dsh：`npm run build:standalone` 会产出 `standalone/batch-hero.js`（含 ag-psd），
配合 `standalone/index.html` 就是一个独立网页工作台（选模板 / 选商品图 / 导入字体 / 导出）。
整合进别的 agent、或只要渲染引擎的做法见 `PORTING.md`。

## 安装

插件目录 `dsh-batch-hero` 已挂进桌面 profile。改完代码：

```bash
cd ~/design/dsh-batch-hero && npm run build
```

刷新 Harness 页面即可。改了 `package.json` 或 `lib/index.js`（宿主侧）需要完全退出再打开 DeepSeek Harness。

> 装进 profile 后 `node_modules/dsh-batch-hero` 必须是指向源码目录的**符号链接**。pnpm 默认硬链接，改 `lib/index.js` 会断链（客户端不受影响，所以容易漏），用 `pnpm install` 重装后记得确认一次：
> `ls -ld ~/.dsh/profiles/desktop/node_modules/dsh-batch-hero`

## 说明

- PSD 渲染用 ag-psd，支持 PSD / PSB、投影、外发光、纯色叠加、渐变叠加、描边、内阴影、剪贴蒙版。
- 内发光、斜面和浮雕、图案叠加不渲染。
- 图层变换（缩放/拉伸/旋转/翻转）只影响导出的合成图，不会写回 PSD。
- 100MB+ 的文件解析在几百毫秒内，首次载入会停顿一下。
