0.3.0 — 命令行入口 + 规则流水线

新增

  • **`psd-batch` 命令行**（`bin/psd.mjs`）：`preflight`、`draft`、`render`、`view`、`check`、`tool`。

    • 不装 dsh 也能跑，Claude Code / Codex / CI / 终端通用。

  • **`src/core/` 九个模块**：`rules`、`mapping`、`sheet`、`text`、`validate`、`view`、`calibrate`、

    • `draft-rules`、`apply-sheet` —— 需求表 + `rules.json` 驱动的批量出图流水线。

  • **预检与校验**：缺图、命名对不上、缺字体、多义匹配都会明确报出，不静默猜测；

    • `check` 输出文字重绘的 drift 报告（宽度比 + 偏移像素）。

  • **文档**：`docs/agent-workflow.md`（工作目录约定与 agent 操作手册）、`docs/lessons.md`（踩坑记录）、

    • `docs/guide.html`（使用教程）。

  • **示例**：`examples/sheet-template.xlsx`（需求表空白模板）、`examples/demo.rules.json`。
  • **字体**：`assets/fonts/` 附 MiSans、GlowSansSC（开源可再分发）。苹果系统字体不入库。

    • 变更

  • `package.json`：新增 `bin`（`psd-batch`），`files` 增加 `bin`/`src`/`docs`，版本 0.3.0。
  • `.gitignore`：排除业务素材目录、`*.xlsx`（保留 examples）、苹果系统字体。
  • `client.js` / `server.js` 重新构建，与源码同步（server.js 682 KiB → 798 KiB）。

    • 兼容性

  • dsh 插件入口与四个工具（`psd_inspect` / `psd_batch_render` / `psd_edit` / `psd_apply_sheet`）

    • 接口未变，0.2.x 的安装方式与参数照旧。
