DSH PSD Batch Studio

PSD 模板 + SKU 抠图 → 批量电商主图。一个内核，两种入口：dsh 插件 / 命令行。

使用教程 从装插件到出第一张图的完整流程，含面板每一块的作用。 Agent 工作流 命令行 / 任意宿主下的目录约定：模板、规则、需求表、产品图、赠品图、输出，以及 preflight → 样张 → 批量 → 校验的流程。 踩坑记录 E01 起的错误现象、根因与正确表述，出新坑就往下编号。 仓库与 Release 源码、Issue、版本下载。命令行：npm i -g dsh-psd-batch-studio，然后 psd-batch help。
