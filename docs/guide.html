开始之前

一次性准备，之后每次出图都不用再做。

  1. 准备一个 agent。Claude Code 或 DeepSeek Harness 都可以。它们要能读写文件夹里的文件、能运行程序、能看图片。
  2. 安装 Node.js（版本 20 或更高）。到 nodejs.org 下载 LTS 安装包，一路点「下一步」即可。这是程序运行需要的基础环境，不需要你懂它。
  3. 解压项目。把收到的压缩包解压到电脑上任意位置，例如桌面。中文路径也没关系。
  4. 让 agent 打开这个文件夹。这一步最关键：agent 的「工作文件夹」必须是项目根目录（里面能看到 模板、产品图、需求表 这些文件夹）。
    你用的 agent怎么做
    Claude Code用 Claude Code 打开项目文件夹（桌面版选择「打开文件夹」，或在 VS Code 里打开该文件夹再启动 Claude Code）。它会自动读取根目录的 CLAUDE.md，了解全部工作规矩。
    DeepSeek Harness把 Harness 的工作目录选为项目文件夹。如果它没有自动读取说明，第一句话告诉它：「先阅读 AGENTS.md，然后按里面的流程工作」。
  5. 让 agent 帮你装好并自检。对它说下面这句，剩下的它自己完成：

2

文件夹说明

一句话：先按类别分文件夹，每个类别里再按「案例」分子文件夹。

什么是「案例」？

一次活动、或一套模板配一批商品，就是一个案例，起一个名字，比如「示范案例」「1111大促」「618新品」。每个类别文件夹里都用同一个案例名建一个子文件夹，这个案例的东西就分别放在里面，不同案例互不混在一起。

每个文件夹放什么

📐
模板 设计师PSD / PSB 模板。只读，工具不会改动它。
📏
规则 设计师每个模板一份规则文件，记录文字、字号、赠品位置等。agent 起草，设计师确认。
📊
需求表 业务每次活动填的商品清单。需求表模板.xlsx 是带填写说明的空白样板，放在这个文件夹的最外层。
📦
产品图 业务产品抠图（透明底 PNG）。文件名 = 需求表里的产品名称。
🎁
赠品图 业务赠品抠图（透明底 PNG）。
🔤
字体包 设计师模板用到的字体文件。PSD 里只记字体名，不含字体本身。案例下没有字体时，会用字体包最外层的字体。
🗒️
说明图 业务业务规则说明图，例如「主图修改说明.png」。agent 会读它。
📤
输出 自动成品都在这里。每次出图在案例下新建一个按时间命名的子文件夹，不会覆盖旧的。
📘
经验手册.md 备查以前踩过的坑。出问题时 agent 会先查它。
⚙️
引擎 程序程序本体，不要动。

四条铁律

① 产品名称 = 图片文件名

需求表写「柔雾定妆蜜粉饼8g」，产品图的案例文件夹里就必须有 柔雾定妆蜜粉饼8g.png。多一个空格都不行，工具永远不会猜哪张图最像。

② 模板只读

模板文件夹里的 PSD 不会被修改。成品是另外画出来的新图片。

③ 不覆盖旧成品

每次出图新建一个文件夹，上一次的结果随时可以回看。

④ 有问题先停

缺图、名字对不上、赠品没登记，预检会直接拦下，让你补完再继续，不会带着错误硬出。

5

检查与修改

图出来了，怎么确认没问题？有问题怎么改？

5.1 你自己看什么

看哪里正确的样子
一级文案数字红色、汉字黑色，两种字号；一行不换行、不被截断
二级文案黑色、大小固定；一级为「/」的商品，这里会变成产品名称
三级文案（价格条里）文案长就会变小，但不会超出白色底条
价格红色，小数点后的数字明显更小（看 19.9、19.8 那几张）
赠品区上下两档，图居中不变形；买即赠为「/」时变成「满99送 + 满159送」
左上角角标NEW / HOT 文字被替换；需求表留空则整块不显示

5.2 让 agent 放大看细节

agent · 批量主图工具放大查看
你
把第一张的上半部分放大 2 倍，加上坐标网格，我看看文字有没有被切。
AI
✓放大 2 倍，网格间隔 100 像素

文字完整，没有被截断。网格每 100 像素一条线，你可以直接用坐标告诉我「再往上 10 像素」。

5.3 常见修改怎么说

你想改什么怎么对 agent 说它会怎么做
某个商品文案或价格写错了「990000000001 的价格改成 59，重出」改需求表那一格（先备份），只重出这一个
只重出几个「把 990000000003 和 990000000004 重新出一遍」只重跑这两个商品
文字太大或太小「三级文案整体再小一点」改规则里的字号参数（先备份），重出样张给你确认
位置偏了「价格条里那行文字往上挪 6 像素」调整该文字层位置，重出样张
想核对和原模板是否一致「核对一下文字的大小和位置有没有和原模板对上」把每个文字层重画一遍与原稿比较，列出偏差
换输出格式「再出一份 PNG」同一批再导出一份
📐
关于「和模板逐像素一致」字号、基线位置、行距、倾斜都是按 PSD 里记录的数值还原的，大多数文字层偏差在 2–5 像素以内。个别层（例如价格数字比原模板窄约 4%）因为字体文件版本不同会有细小差异。核对时 agent 会把这些偏差明确列给你。

给设计师。拿到一个全新的 PSD，没有任何规则文件，也能做：agent 先读模板起草规则，再对照业务说明补全，最后样张确认。

6.4 样张确认，以后复用

规则补完后，流程和第 3 章一样：预检、样张、确认。新模板第一次必须人工看样张，因为自动识别在结构特别的模板上可能认错图层。确认没问题后，规则就留在 规则/你的案例名 文件夹里，以后同一个模板的活动直接复用（新案例里用 --rules 的方式指向它，让 agent 来做就行），业务同学不用再碰它。

👀
设计师要特别看的 3 处① 角标字体是否缺失；② 文字最长的商品有没有撑出底条；③ 赠品名是否真的对到了赠品图。

常见问题

点开看答案。

agent 说预检有问题，我不想补图，能先出能出的吗？

可以。对它说「把缺图的商品先去掉，其余的先出」。它会先问你确认，备份需求表后再把这几行整行删掉，然后继续。它不会自己换图。

提示「字体 xxx 未找到，将用替代字体」是什么意思？

模板里用了某个字体，但字体包里没有这个字体文件，工具改用了电脑里的相近字体，字形会和模板略有差别。请设计师把缺的字体文件放进字体包，再重出。示例模板里目前缺 AuliareRegular（NEW 角标的英文字母），NEW 字样会比原版略大。

出来的图文字被截断了，或者压到别的元素

把图发给 agent，说「第 3 张三级文案超出白条了」。它会放大确认，再调整该文字的宽度适配或字号，重出样张。文案特别长（20 字以上）时，自动缩小后可能小到不好看，建议改短文案。

想用另一份需求表，或者同一个文件里的另一个工作表？

直接说「用 618大促 案例里的另一份需求表出图」或「用 Sheet2 那个工作表出图」。

能出 PNG 或其他尺寸吗？

格式支持 jpg、png、webp，说「再出一份 PNG」即可。尺寸由模板画布决定（示例模板是 1280×1280）。想要别的尺寸，需要设计师另做一个模板。

出图很慢，或者提示内存不够？

模板很大（几百 MB）时，第一张要花十几秒读取模板，之后同一批更快。示例：2 张样张约 7 秒，7 张整批通常一分钟内。内存不够时，关掉其他大程序，或让 agent 分几批出。

agent 没按流程来（比如没做预检就出图）

对它说：「先完整阅读项目根目录的 AGENTS.md，然后按里面的流程重新做。」绝大多数偏差这样就能纠正。

别人给的需求表，列名和你们的不一样怎么办？

工具认识常见的叫法，比如「商家编码 / sku编码」「产品名称 / 商品名称」「活动S价 / 活动价」「一级卖点文案 / 利益点」。不认识的列，告诉 agent「这一列是价格」，它会补进规则。

报了一个看不懂的错误

把报错整段发给 agent。它会先查经验手册（里面是历史踩坑记录），解决后把新问题补进去。
